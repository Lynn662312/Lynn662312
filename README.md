## About

I enjoy building practical applications that connect AI, backend services, databases, and deployment. My project experience includes REST API and frontend/backend integration, AI-powered features, Firebase and SQL-backed applications, and collaborative mobile products.

I use AI-assisted coding tools as part of my workflow, while focusing on understanding, reviewing, testing, and integrating the code into a complete application.
